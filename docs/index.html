// Key Features

Capabilities

🔍

Protocol-Based ML Backends

Swappable detection backends via Python protocols. Ship with YOLOv5 and ONNX Runtime out of the box, add custom models without touching core code.

📹

Multi-Camera Support

USB and RTSP camera feeds with concurrent processing. Add, remove, and configure cameras at runtime through the management API.

🔒

JWT + RBAC Authentication

Role-based access control with JWT tokens. Admin, operator, and viewer roles with fine-grained endpoint permissions.

⚡

Circuit Breaker Pattern

Resilient service communication with automatic circuit breaking, preventing cascading failures across detection and alert subsystems.

📊

Prometheus + Grafana

11 custom Prometheus metrics covering detection latency, alert throughput, camera health, and model inference performance.

🔔

4 Alert Channels

Email, WebSocket, Webhook, and Sound alerts with configurable thresholds and per-channel routing rules.

// Quick Start

Get Running

terminal 
# Clone the repository
git clone https://github.com/DarthAether/threat-identification-system.git
cd threat-identification-system

# Copy environment config
cp .env.example .env

# Start all services
docker-compose up -d

# Access services
# API:        http://localhost:8000/docs
# Grafana:    http://localhost:3000
# Prometheus: http://localhost:9090

# Run test suite
docker-compose exec api pytest -v --cov
